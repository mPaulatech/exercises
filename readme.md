# Exercicios:
Este repositório tem como objetivo reunir todos os exercícios de várias linguagens que faço para aprender.

## exClaude:
Os exercícios do exClaude foram gerados pela IA Claude com base em um ZIP das aulas de JavaScript, com o intuito de aprendizado.
As questões são:

1. Crie um objeto `produto` com nome, preço e estoque. Sem usar template string, monte a frase `"O produto X custa R$Y"` com concatenação (`+`).

2. Reescreva a função `Verificador` do seu `DesafioJsES6+2` usando `switch` em vez de `if/else`.

3. Some todos os números pares de 1 a 50 usando `for`. Depois refaça com `while`.

4. Crie `mediaTurma(notas)`, que recebe um array de notas e retorna a média, sem usar `reduce` — use `for`.

5. Refaça o exercício 1 usando crase e `${}`.

6. Converta `mediaTurma` (exercício 4) para uma arrow function.

7. Dado `const produto = {nome, preco, estoque}`, extraia `nome` e `preco` em uma linha. Depois faça o mesmo com um array `[primeiro, , terceiro]`, pulando o segundo item.

8. Una dois arrays de produtos em um só sem duplicar. Depois clone um objeto `produto`, alterando apenas o preço.

9. Crie `somarTodos(...numeros)`, que soma quantos argumentos forem passados.

10. Valide um e-mail simples: deve conter `@` (`includes`) e não pode começar com número (`startsWith`).

11. Com o array `products` do seu `DesafioJsES6+2`: calcule o valor total do estoque com `reduce` e liste apenas os nomes (`map`) dos produtos com preço maior que 5.

12. Crie uma função `buscarProduto(id)` que retorna uma Promise, resolvendo depois de 1 segundo se o `id` existir em um array fixo, ou rejeitando se não existir.

13. Reescreva seu `nutriApp()` de `ES6+/requisiçõesHttps/`, trocando `.then/.catch` por `async/await` com `try/catch`.

14. Transforme o objeto `pessoa` (visto em `objetos/` e `ES6+/desconstruindo/`) em uma `class Pessoa` com construtor e um método `apresentar()`.

15. Refaça a lista `products` como um `Map` (chave = nome, valor = preço) e busque um preço por nome.
